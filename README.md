# System Design Learning Repository

Welcome to my System Design learning repository! This repository is structured to cover both theoretical concepts and practical implementations of system design.

## Repository Structure

### Basics
The `Basics` directory contains fundamental concepts and resources for:
- Database Management Systems (DBMS)
- Computer Networks
- Operating Systems (OS)
- Object-Oriented Programming (OOPs)
- System Design Principles
- Design Patterns

### Low Level Design (LLD)
The `LLD` directory contains practical implementations of various design problems, including:
1. [Snake and Ladder](https://workat.tech/machine-coding/practice/snake-and-ladder-problem-zgtac9lxwntg)

## Purpose
This repository serves as:
1. A learning journal for system design concepts
2. A collection of practical implementations
3. A resource hub for others learning system design

Feel free to explore and learn along with me!
